# imgcrop

画像をトリミングするためのDenoベースのコマンドラインツールです。グリッド状の分割やInstagram向けの投稿画像を作成するための特化機能を備えています。

## 機能

- 画像を指定した1つ以上の領域に切り抜きます。
- 1つの画像を、サイズ、オフセット、ギャップ（間隔）を指定してグリッド状に分割します。
- Instagramの複数画像投稿に最適なサイズと間隔で画像グリッドを生成します。
- PNGおよびJPEG形式をサポートしています。

## 必要条件

- [Deno](https://deno.land) ランタイム環境

## 使い方

本ツールは、異なるトリミング用途に応じた3つのスクリプトで構成されています。出力ファイルは入力ファイルと同じディレクトリに保存され、ファイル名に `_<番号>` のサフィックスが付きます（例: `input_1.jpg`、`input_2.jpg`）。

### 1. 基本トリミング (`imgcrop.js`)

画像を指定した1つ以上の矩形領域に切り抜きます。

**コマンド:**

```sh
deno run -A imgcrop.js <input_file> <x,y,w,h> [<x,y,w,h>...]
```

- `<input_file>`: 元画像のパス（例: `test.jpg`）。
- `<x,y,w,h>`: 切り抜く領域を定義するカンマ区切りの文字列（`x`座標、`y`座標、`幅`、`高さ`）。複数の領域を指定可能です。

**例:**

```sh
deno run -A imgcrop.js test.jpg 100,100,500,500 200,200,500,500
```

このコマンドは、指定された座標から `test_1.jpg` と `test_2.jpg` の2つのファイルを生成します。

### 2. グリッドトリミング (`imgcroprepeat.js`)

元画像を小さな画像のグリッド状に分割します。

**コマンド:**

```sh
deno run -A imgcroprepeat.js <input_file> <offx,offy,w,h,gapw,gaph,nw,nh>
```

- `<offx,offy>`: グリッド左上隅の開始 `x,y` 座標。
- `<w,h>`: 切り抜く各画像の `幅` と `高さ`。
- `<gapw,gaph>`: 各画像間の水平および垂直のギャップ（ピクセル単位）。
- `<nw,nh>`: グリッドの列数（`nw`）と行数（`nh`）。

**例:**

```sh
deno run -A imgcroprepeat.js test.jpg 4,4,616,616,7,7,3,3
```

このコマンドは、3×3のグリッド（合計9枚の画像、`test_1.jpg` から `test_9.jpg`）を生成します。各画像は616x616ピクセルで、7ピクセルのギャップを空け、(4,4) のオフセットから開始して切り抜かれます。

### 3. Instagramグリッドトリミング (`imgcropinsta.js`)

Instagramの複数画像投稿機能に最適化された正方形画像のグリッドを生成します。出力ファイルは逆順に番号付けされるため、順番に（`_1`、`_2` のように）アップロードするだけで、プロフィールのグリッドに正しく表示されます。

**コマンド:**

```sh
deno run -A imgcropinsta.js <input_file> <offx,offy,imgw,nw,nh,pcmode>
```

- `<offx,offy>`: グリッド左上隅の開始 `x,y` 座標。
- `<imgw>`: 各正方形画像の幅と高さ（例: 標準的なInstagram投稿の場合は `1080`）。
- `<nw,nh>`: グリッドの列数（`nw`）と行数（`nh`）。
- `<pcmode>`: ギャップ計算モードを設定します。
    - `0`: スマートフォンモード（388pxを基準とした小さなギャップ）。
    - `1`: PCモード（618pxを基準とした大きなギャップ）。

**例:**

```sh
deno run -A imgcropinsta.js test.jpg 0,0,1200,3,2,0
```

このコマンドは、スマートフォン表示に最適化された3×2のグリッド（6枚の画像）を生成します。各画像は1200x1200ピクセルです。出力ファイル（`test_1.jpg` から `test_6.jpg`）は、正しくアップロードできる順番で番号付けされます。
